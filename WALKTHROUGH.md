# VoxTube — 60-second screen walkthrough

Silent, captioned sequence of real prototype screenshots, captured 18 October 2026.
Not continuous interaction footage or a live collection/model-performance demonstration.
All visible comments, classifications and run history are synthetic.

| Time | On screen | The point |
| --- | --- | --- |
| 0–12 seconds | Overview | Turn scattered product discussion into a question worth investigating. |
| 12–24 seconds | Overview | Price is one leading concern, not a verdict. Keep the base and quote visible. |
| 24–36 seconds | Evidence | Inspect the actual wording: monthly payment, equipment or alternatives? |
| 36–48 seconds | Trends | Revisit the same question. A change in collected comments is not proof of a market shift. |
| 48–60 seconds | Overview | The value is the connection between problem framing, a working tool and analytical judgment. |

The example has 24 fictional comments. Price and software each have three negative
comments. The illustrative negative-share change is −12.5 percentage points; it is
not an observed market trend or a significance test.

The selected evidence checkbox is an actual UI state. This video does not show a
saved finding, export download or generation, and makes no claim that those actions
happened during capture. Source code and data stores remain private.
